Whitebox Writing Lab 0.4.6 QQ Share Edition

Quick start:
1. Extract the complete ZIP. Do not run it inside the archive.
2. Double-click StartWhiteboxPortable.bat.
3. Whitebox opens automatically in the default browser.
4. Open Settings and add a provider connection.
5. Enter a connection name, an OpenAI-compatible Base URL, and your own API key.
6. Click Test and fetch models. The fetched models can then be selected in workflow nodes.

No Python, Node.js, npm, WSL, PowerShell 7, or administrator access is required.

Security:
- This package contains no sender API key, personal novel, or database.
- Project files and API keys are stored only in the local data folder after first use.
- Do not forward a package after using it unless the data folder has been removed.
- The service listens only on 127.0.0.1:8001.
- Use StopWhitebox.bat to stop the local background service.
